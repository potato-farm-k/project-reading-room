# Web Foundation Learning Path

이 문서는 Web Foundation Learning Track의 전체 학습 순서와 진행 상태를 관리합니다.

> 번호와 순서는 향후 학습 과정에서 변경될 수 있습니다.

## 초기 학습 로드맵

| 번호 | 주제 | 학습 질문 | 상태 |
| --- | --- | --- | --- |
| WEB-001 | 웹은 어떻게 동작하는가 | 주소를 입력한 뒤 화면이 나타날 때까지 무슨 일이 일어나는가? | 초안 작성 |
| WEB-002 | 브라우저 | 브라우저는 문서와 코드를 어떻게 읽고 실행하는가? | 계획 |
| WEB-003 | HTML | 웹 문서의 구조와 의미를 어떻게 표현하는가? | 계획 |
| WEB-004 | CSS | 구조와 표현을 왜 분리하며 화면은 어떻게 배치되는가? | 계획 |
| WEB-005 | JavaScript | 웹 페이지에 상태와 동작을 어떻게 더하는가? | 계획 |
| WEB-006 | HTTP | Client와 Server는 어떤 규칙으로 요청과 응답을 주고받는가? | 계획 |
| WEB-007 | REST API | 웹 자원과 작업을 일관된 인터페이스로 어떻게 표현하는가? | 계획 |
| WEB-008 | CORS | 브라우저는 왜 출처가 다른 요청을 제한하는가? | 계획 |
| WEB-009 | Serverless | 서버를 직접 운영하지 않고 코드를 실행한다는 것은 무엇인가? | 계획 |
| WEB-010 | GitHub Pages Architecture | 정적 파일은 GitHub Pages에서 어떻게 빌드되고 배포되는가? | 계획 |

## 진행 원칙

- 현재 파일이 있는 Guide는 `WEB-001`뿐입니다.
- `WEB-002` 이후 문서는 해당 주제를 실제로 학습할 때 만듭니다.
- 프로젝트에서 먼저 만난 주제가 있다면 순서를 조정할 수 있습니다.
- Guide를 읽은 뒤 실습 결과와 새 질문을 해당 문서에 기록합니다.
