# Prompt Library

## 목적

반복해서 사용하는 AI 협업 프롬프트를 모아두는 공통 문서입니다.

## Codex 요청 기본 구조

1. 작업 목적
2. 현재 전제
3. 작업 대상 파일
4. 구현할 것
5. 제외할 것
6. 완료 조건
7. 확인 방법
8. 추천 커밋 메시지

> 좋은 프롬프트는 작업의 경계와 완료 조건을 함께 설명합니다.
