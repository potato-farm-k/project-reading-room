# AI Collaboration Workflow

아이디어를 대화에만 남겨두지 않고 검토 가능한 결과와 기록으로 연결하는 작업 흐름입니다.

## 작업 흐름

1. 문제와 원하는 결과를 짧게 정의합니다.
2. 현재 파일과 제약 조건을 함께 확인합니다.
3. 작은 단위로 구현하고 바로 검증합니다.
4. 결정과 남은 일을 문서 및 Git에 기록합니다.

> AI의 제안은 출발점이며, 최종 판단과 검증은 프로젝트 맥락을 기준으로 합니다.
