# Vibe Coding Habit Guide

AI와 함께 개발할 때 채팅 내용을 일회성 답변으로 끝내지 않고,
내 판단 기준과 문서 습관으로 바꾸기 위한 공통 가이드입니다.

## 기본 루틴

1. 질문한다.
2. 답변을 읽는다.
3. 결정 사항을 분리한다.
4. 필요한 문서에 반영한다.
5. Codex 작업 지시서로 바꾼다.
6. Git으로 기록한다.
